## 📌 Resumen del proyecto
**BarrioLink** es una plataforma web diseñada para mejorar la gestión interna y la comunicación en comunidades residenciales. Su propósito es conectar administradores, vecinos y encargados de gestión para centralizar información, facilitar la coordinación y fortalecer la participación comunitaria.

El sistema contempla funcionalidades como:
- Gestión de usuarios y roles (anónimo, registrado, miembro, administrador)  
- Publicaciones y avisos internos  
- Gestión de eventos del barrio  
- Solicitudes y trámites internos  
- Categorías configurables por cada comunidad

El objetivo principal es modernizar la comunicación comunitaria mediante herramientas accesibles, intuitivas y escalables.

## 🧩 Tecnologías utilizadas
- **Backend:** Django REST Framework  
- **Frontend:** Angular  
- **Base de datos:** PostgreSQL (Azure Flexible Server)  
- **Infraestructura:** Azure App Services  
- **Repositorio principal:** GitHub con submódulos  
- **CI/CD:** Azure DevOps Pipelines (YAML)
